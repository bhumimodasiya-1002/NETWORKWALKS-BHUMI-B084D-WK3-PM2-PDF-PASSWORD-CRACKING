# Week 3: PDF Password Recovery & Hash Analysis 🔐

This repository contains my Week 3 practical work completed during the **Cybersecurity & Ethical Hacking Internship at Networkwalks**.

The tasks focused on understanding password recovery techniques, hash extraction, and dictionary-based attacks using different tools.

## 📌 Practical Tasks

### Task 1: Password Recovery Using John the Ripper

- Set up John the Ripper and Johnny GUI on Windows.
- Extracted the password hash from a protected PDF.
- Used a dictionary attack to analyze the hash.
- Successfully recovered the PDF password.

### Task 2: Password Recovery Using Networkwalks Tools

- Explored Networkwalks Hash Calculator.
- Used the online Password Cracker tool.
- Practiced hash analysis and password recovery through a browser.
- Completed the process without installing additional software.

## 🧠 Skills & Knowledge Gained

- PDF password hash extraction.
- Hash analysis techniques.
- Dictionary-based password attacks.
- Working with command-line and GUI tools.
- Understanding password security practices.
